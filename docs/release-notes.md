# 変更履歴

## [v1.0.0] - 2026-10-18 Windows 11開発環境・構成整理と診断処理の改善

【変更】Windows 11での開発・ビルドと診断処理を整理。以下を今回の公開予定版へまとめる。

- フォルダ構成・不具合を再点検し、WindowsでIMG生成と整合性検査に合格。ソースは既存のGitアップロード共通ツールの8番からmainへ送信し、IMGはGitHubへ含めない。
- common.shの処理をsrc/libへ役割別に分離し、PC InfoとStorage Healthのドライブ列挙・接続方式判定を共通化。
- lsblk JSONをjqで解析する処理へ整理し、pairs形式・sysfsの代替経路を維持。
- PC Infoのlscpu・BIOS/ベースボード/CPUのDMI情報を表示ごとに一度取得し、DMI解析を共通化。表示項目・数値書式・GPU/SMART判定・ドライバ操作は維持。
- CU・VRAMログ解析のPCI/DRM関連付けを共通化。GPUルールと解析結果を維持したままgpu_logs.jqへ集約。
- 設定読込み・検査と同梱ファイルの配置・権限・原本照合を共通モジュールへ分離し、検証入口からビルド入口への依存を解消。
- USB・APK・必須ツールの準備失敗時に診断メニューへ進ませず、理由と再試行操作を表示。
- Memtestの入力失敗・再起動要求失敗・再起動待ちのタイムアウトを処理し、開始失敗時は一回起動フラグの取消しを試行。
- 起動設定・生成処理・依存定義等を含む入力一覧とSHA-256をmanifestへ記録し、追加・削除・変更及びビルド開始・終了時の差分を検出。記録のない旧IMGは再ビルドを要求。
- GPUの情報・復旧結果をページ送りに変更。途中ページからのq操作に対応。
- 複数USBを接続しない利用者指定の運用条件を記録し、媒体の探索方式は維持。
- Storage HealthをsmartctlのJSON・終了コードによる判定へ変更。SASの故障予告や取得失敗を正常扱いせず、判定理由を表示。jqを同梱設定へ追加。
- GPUの既存判定ルールを維持し、AMD CU情報のPCI/DRM対応とKFDによる取得を追加。PCIドメインとDRM実パスの扱いも修正。
- GPU Testを英語のGPU Driver Checkへ変更。初回表示の自動復旧を除去し、rキーによるモジュール読み込みに限定。画面用ドライバの強制解除・PCI再プローブを除去。
- Memtestの繰り返し実行・Escでの再起動を画面に明示。日本語表示は追加しない。
- Windowsで診断解析・シェル構文と操作境界を検査するテストと、検証.cmd --tests-onlyを追加。診断修正後のIMG生成と内容検証を実施。実機確認は別PCで行う。

- 利用者の指定により、ドライバーソースビルド用の追加コード・試験用モジュール・専用設定とテストを削除。
- 不要になったLLVM・Cygwin・MSYS2環境、開発ヘッダー・ソース、取得キャッシュとzstandard依存を整理。
- セットアップ・IMG生成・内容検証の3つの入口へ統一。Windows 11でオフライン再ビルド、9件の回帰テストとIMG整合性検査が合格。
- Alpine標準ドライバの読み込み設定、診断処理、GPU判定ルールと復元用IMGを維持。実機確認は別PCで行う。
- 開発環境をWindows 11・Python 3.12へ移行。Docker・WSLへの依存を除去。
- 既存IMGを流用せず、公式配布物からOS・診断ツール・BIOS/UEFI起動部・自作コードを組み立てるWindowsビルドを追加。
- BIOS起動をSyslinuxからGRUBへ変更し、MBR＋FAT32のIMGを生成。x86_64 UEFIもWindows版GRUBで生成。
- Alpineを同じ3.21系列の3.21.8、GRUBを2.14に設定。Memtest86+は8.00を維持。
- GPU判定ルールを`data/gpu/`、調査一覧を`docs/gpu/`、ビルド処理を`tools/`へ整理。
- 完成品を`build/output/`、中間物を`build/work/`へ統一。
- 自作のLinux起動処理2本を`src/boot/`へ移動し、配布設定・テンプレートと分離。IMG内の配置・内容・実行権限は維持し、原本との照合対象へ追加。
- READMEと設計書の配置・編集場所を更新し、未公開作業の履歴を一つへ集約。
- 取得チェックサム、依存閉包、Linuxファイル属性、IMG同梱内容を照合する検証を追加。
- 既存の診断画面・GPU判定ルールの内容を維持。実機でのBIOS/UEFI起動・診断は別PCで確認する。

公開準備中で、GitHubへの送信は未実施。既存のタグ・リリースがないことを確認し、共通ツールで必要な最初の版付き履歴をv1.0.0として整理した。作業途中の番号やGitHub Releaseは作成しない。
